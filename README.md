# 贪吃蛇 · 网页版

一个用纯 HTML/CSS/JavaScript 编写的经典贪吃蛇游戏，单文件、零依赖，打开浏览器即可游玩。

## 玩法

- 用方向键 `↑ ↓ ← →` 或 `W A S D` 控制蛇的移动
- 按 `空格` 暂停 / 继续，按 `Enter` 快速开始
- 吃到食物得分，撞墙或咬到自己则游戏结束

## 道具

| 图标 | 效果 |
|------|------|
| 🍎 | 普通食物 +10 分 |
| ⭐ | 星星食物 +30 分，限时出现（即将消失时会闪烁），每吃 5 个苹果刷新一颗 |

## 特性

- 得分越高速度越快
- 最高分保存在浏览器本地（localStorage），刷新不丢失
- 蛇身渐变和眼睛、苹果 / 旋转星星动画
- 移动端支持：滑动屏幕或使用虚拟方向键

## 运行

直接用浏览器打开 `snake.html`，无需任何服务器或构建步骤。
